Infrastruktur Teknis & Arsitektur Logika Sistem

Infrastruktur Dasar

Backend BuwohApp dibangun dengan arsitektur berbasis Node.js yang modular dan skalabel.

Node.js (Express) Prisma ORM PostgreSQL / MySQL JWT Authentication Zod Validation

Struktur ini dipilih untuk memastikan performa yang cepat dalam menangani query database kompleks terkait manajemen sumbangan dan relasi antar pengguna.

Relasi Database (ERD Concept):

  • User Table: Menyimpan profil, password (hashed), dan status akun.
  • Event Table: Menyimpan koordinat GPS, deskripsi hajatan, dan ID Tuan Rumah.
  • Contribution Table: Menghubungkan User ke Event dengan metadata nominal dan timestamp.

User Story Flow

1. Tamu (Guest Story)

"Sebagai tamu, saya ingin melihat daftar hajatan di sekitar lokasi saya agar saya bisa melakukan 'buwuh' secara praktis tanpa membawa uang tunai."

Flow: Open App → GPS Scan → Select Event → Enter Amount → Send → Success.

2. Tuan Rumah (Host Story)

"Sebagai tuan rumah, saya ingin mendaftarkan acara saya ke sistem agar tamu bisa menyumbang secara digital dan saya punya catatan yang rapi."

Flow: Login → Create Event → Set Location → Monitor Contributions → Export Report.

3. Sistem (System Logic)

"Sistem harus memvalidasi setiap transaksi dan memastikan koordinat GPS akurat untuk mencegah kesalahan input lokasi hajatan."

Logika Utama (Core Business Logic)

1. Manajemen Event (Hajatan)

  • Tuan rumah dapat membuat event dengan detail lokasi (GPS coordinates), waktu, dan kategori.
  • Sistem menghasilkan Unique Event ID yang digunakan untuk verifikasi sumbangan.

2. Sistem Sumbangan (Digital Buwuhan)

  • Setiap sumbangan dicatat dengan relasi User (Penyumbang) → Event (Tuan Rumah).
  • Mendukung pencatatan nominal, pesan (doa), dan status pembayaran.

3. Real-time GPS & Agenda

  • Logika backend menghitung jarak antara lokasi user saat ini dengan lokasi event.
  • Filter agenda otomatis berdasarkan radius lokasi dan rentang waktu (D-7 hingga H+1).

System Flow (Alur Sistem)

1
Autentikasi: User login via Mobile → Backend memverifikasi kredensial → Mengembalikan JWT Token.
2
Discovery Event: Mobile mengirim koordinat GPS → Backend melakukan filter spasial di database → Mengembalikan daftar hajatan terdekat.
3
Proses Buwoh: User memilih nominal → Backend mencatat transaksi → Update saldo/laporan tuan rumah secara real-time.

Keamanan & Integritas Data

  • Password Hashing: Menggunakan bcrypt untuk mengenkripsi data sensitif pengguna.
  • Middleware Validation: Setiap request API divalidasi menggunakan skema Zod untuk mencegah dirty data.
  • Relational Integrity: Menggunakan Prisma Constraints untuk memastikan catatan sumbangan tidak terhapus jika data user atau event masih aktif.
