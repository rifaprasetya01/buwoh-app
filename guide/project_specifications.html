Dokumentasi Fitur, Database, dan Alur Pengguna

Daftar Fitur Aplikasi

Fitur-Fitur Utama

  • Digital Buwoh (Sumbangan): Proses pengiriman dana atau barang secara digital dengan pencatatan real-time.
  • Manajemen Event (Hajatan): Fitur bagi host untuk membuat acara, menentukan lokasi GPS, dan kebijakan pemberian.
  • Radius Discovery: Pencarian otomatis acara hajatan terdekat berdasarkan koordinat GPS pengguna.
  • Dashboard Host: Laporan lengkap mengenai tamu yang hadir dan rincian sumbangan yang diterima.
  • Katalog Rekomendasi: Pengaturan barang bawaan yang disarankan atau diwajibkan oleh penyelenggara acara.

Fitur-Fitur Tambahan/Pendukung

  • Digital Prayers: Kolom doa dan ucapan dari tamu untuk tuan rumah yang tersimpan secara permanen.
  • Notifikasi Real-time: Pemberitahuan saat ada event baru di sekitar atau saat sumbangan berhasil dikonfirmasi.
  • History & Logs: Rekam jejak seluruh aktivitas 'buwuhan' yang pernah dilakukan pengguna.
  • User Profile & Location: Manajemen data diri dan koordinat lokasi tetap pengguna.

Strategi Soft Delete

Untuk menjaga integritas data histori sumbangan, sistem menerapkan Soft Delete pada entitas utama:

  • User & Event: Tidak dihapus permanen untuk menjaga relasi laporan keuangan/barang milik Host.
  • Integritas Relasi: Record pada gifts akan tetap ada meskipun User atau Event terkait ditandai sebagai dihapus (deleted).
  • Constraint: Menggunakan onDelete: Restrict pada level database untuk mencegah kehilangan data transaksi secara tidak sengaja.

Database Table Relations

Daftar Relasi Tabel:

  • USER one to many EVENT (Sebagai Host yang menyelenggarakan acara).
  • EVENT one to many GIFT_RECOMMENDATION (Satu acara memiliki banyak kategori rekomendasi barang).
  • GIFT_RECOMMENDATION one to many RECOMMENDATION_DETAIL (Satu kategori rekomendasi memiliki banyak rincian item).
  • USER many to many EVENT melalui tabel GIFT (User sebagai tamu yang memberikan sumbangan ke berbagai acara).
  • GIFT one to many GIFT_DETAIL (Satu catatan pemberian/buwohan berisi banyak rincian barang/uang).
  • EVENT one to many GIFT (Satu acara menerima banyak pemberian dari berbagai tamu).

User Story Flow

Story 1: Host Membuat Acara

Sebagai Host, saya mendaftarkan akun, lalu membuat event baru dengan menentukan koordinat GPS dan memberikan daftar rekomendasi barang agar tamu tahu apa yang saya butuhkan.

Story 2: Tamu Menemukan Acara

Sebagai Tamu, saya membuka aplikasi saat berada di lokasi hajatan, sistem secara otomatis mendeteksi acara terdekat, dan saya bisa memilih acara tersebut untuk melihat detailnya.

Story 3: Proses 'Buwuh' Digital

Sebagai Tamu, saya memilih item yang saya bawa (berdasarkan rekomendasi host atau input manual), sistem mencatat sumbangan saya, dan saya bisa meninggalkan pesan doa digital.

Story 4: Rekapitulasi Data

Sebagai Host, setelah acara selesai atau saat acara berlangsung, saya melihat dashboard untuk memantau siapa saja yang sudah menyumbang dan apa saja barang yang saya terima secara mendetail.
