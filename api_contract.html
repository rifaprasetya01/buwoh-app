BUWOH APP API

Pre-Backend Preparation Contract. Dokumen ini mendefinisikan struktur pertukaran data antara aplikasi mobile (Frontend) dan API server (Backend).

Authentication

POST /api/v1/auth/register

Mendaftarkan pengguna baru menggunakan email dan kata sandi.

Request Body
{
  "email": "user@email.com",
  "password": "secure_password",
  "password_confirmation": "secure_password"
}
Success Response (201)
{
  "status": "success",
  "message": "User registered",
  "data": {
    "token": "eyJhbGci..."
  }
}
POST /api/v1/auth/login

Autentikasi pengguna dan mendapatkan token akses.

Request Body
{
  "email": "user@email.com",
  "password": "password123"
}
Success Response (200)
{
  "status": "success",
  "data": {
    "token": "eyJhbGci...",
    "user": { "id": 1, "name": "Budi" }
  }
}

User Profile

GET /api/v1/user/profile

Mendapatkan data profil lengkap pengguna yang sedang login.

Headers
Authorization: Bearer [token]
Response (200)
{
  "name": "Rifa Prasetya",
  "address": "Sleman, Yogyakarta",
  "photo_url": "https://...",
  "stats": {
    "total_buwoh": 15,
    "total_events": 3
  }
}
PUT /api/v1/user/profile

Memperbarui informasi profil pengguna.

Request Body (Multipart)
{
  "name": "New Name",
  "address": "New Sleman",
  "photo": [binary_file]
}
Response (200)
{
  "status": "success",
  "message": "Profile updated"
}

History / Contributions

GET /api/v1/history?filter=Uang&query=dian

Mendapatkan daftar riwayat kontribusi (buwoh). Mendukung filter kategori dan pencarian nama/acara.

Query Parameters
filter: "Semua" | "Uang" | "Beras" | "Gula"
query: string (search term)
Response Data Item
{
  "id": "uuid",
  "jenis": "Hajatan Pernikahan",
  "is_balas_budi": true,
  "tanggal": "10 Nov 2023",
  "nama_acara": "Resepsi Bagus & Siti",
  "host": "Bapak Slamet",
  "kontribusi": [
    { "type": "uang", "label": "Rp 300.000" }
  ],
  "status": "diterima",
  "tags": ["Uang"]
}

Events Management

POST /api/v1/events

Membuat acara (hajatan) baru oleh pengguna.

Request Body
{
  "title": "Syukuran Kelahiran",
  "date": "2024-05-20",
  "location": "Gamping, Sleman",
  "description": "..."
}
Response (201)
{
  "status": "success",
  "data": { "event_id": 101 }
}
